Vanilla host

This page has zero Vue / Pinia / Tailwind from the Support app. The snippet below is the install surface: public data-widget-id and data-locale only. 

<script
  src="/loader.js"
  data-widget-id="wid_public_example"
  data-locale="fa-IR"
  async
></script>

Session: setSession is a generation bump, not a login. The iframe credential is the user-token / staff-token cookie on a same-site cookie domain. There is no login form here and tokens are not written to localStorage or the URL. If you are not already logged in on that cookie domain, AUTH_REQUIRED is expected and correct.

Run the module with yarn dev (default http://localhost:5173) and this page via yarn workspace @nipoto/support-loader example (http://localhost:4174). Staff console: add data-side="staff" on the loader script (uses the staff-token cookie), then setSession and navigate ticket.list. Or open the module directly at http://localhost:5173/#/ticket/list (fixture demo).
